# Step 1.4: SOC Detection Cards (Rules 01–10)

| Rule ID | Rule Title | MITRE ATT&CK | Log Source / EventCode | Severity | True Positive Trigger | Known Benign / False Positives | Initial Triage Steps |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Rule 01** | Suspicious PowerShell Execution | `T1059.001` (Execution) | `WinEventLog:Security` (`4688`), `PowerShell` (`4104`) | **High** | Encoded commands (`-enc`), `IEX`, `DownloadString` | `SYSTEM` or Splunk Universal Forwarder helper scripts (`splunk-powershell.exe`) | Inspect `Process_Command_Line`, `Creator_Process_Name`, and `Account_Name`. Exclude `Account_Name="SYSTEM"`. |
| **Rule 02** | Scheduled Task Creation | `T1053.005` (Persistence) | `WinEventLog:Security` (`4688`, `4698`) | **Medium** | `schtasks.exe /create` or task registration event `4698` | Windows Update or legitimate software updaters running as `SYSTEM` | Check task command path (`TaskContent` / `Process_Command_Line`) and creating user account. |
| **Rule 03** | Windows Service Creation | `T1543.003` (Persistence) | `WinEventLog:System` (`7045`), `Security` (`4697`, `4688`) | **Medium** | `sc.exe create` or new service installation | Authorized software deployments or driver installations | Verify `Service_File_Name` binary path, digital signature, and `Account_Name`. |
| **Rule 04** | LSASS Memory Credential Dumping | `T1003.001` (Credential Access) | `WinEventLog:Security` (`4688`), Sysmon (`10`) | **Critical** | `rundll32.exe ... comsvcs.dll, MiniDump` targeting `lsass.exe` | Endpoint Detection & Response (EDR) agents or crash dump utilities | Immediately isolate host (`DESKTOP-DTUQ6D4`), rotate credentials, and check output dump path. |
| **Rule 05** | Brute Force Followed by Success | `T1110` (Credential Access) | `WinEventLog:Security` (`4625`, `4624`) | **High** | $\ge 3$ failed logons (`4625`) followed by `4624` within 10m | User mistyping password multiple times after password rotation | Check `Logon_Type` (`3` = Network, `10` = RDP), source IP/workstation, and post-logon commands. |
| **Rule 06** | Clearing Windows Event Logs | `T1070.001` / `T1685.005` (Defense Evasion) | `WinEventLog:Security` (`1102`), `System` (`104`), `4688` (`wevtutil`) | **High** | `wevtutil cl Security` or `Application` | Rare scheduled maintenance by authorized system administrators | Treat as high-confidence indicator of anti-forensics; inspect events immediately preceding `1102`/`104`. |
| **Rule 07** | Rundll32 Proxy Execution | `T1218.011` (Defense Evasion) | `WinEventLog:Security` (`4688`) | **Medium** | `rundll32.exe` invoking `javascript:`, `comsvcs.dll`, or temp DLLs | Native Windows Control Panel applets (`shell32.dll,Control_RunDLL`) | Inspect DLL path and exported function arguments in `Process_Command_Line`. |
| **Rule 08** | Ingress Tool Transfer | `T1105` (Command & Control) | `WinEventLog:Security` (`4688`) | **Medium** | `certutil.exe -urlcache -f`, `curl.exe`, or `Invoke-WebRequest` | Developer scripts fetching internal packages via `curl` | Extract remote URL/IP, compute SHA-256 hash of downloaded file, and block C2 subnet. |
| **Rule 09** | Linux Cron Job Persistence | `T1053.003` (Persistence) | `linux:audit` (`/var/log/audit/audit.log`, `key="cron_persistence"`) | **Medium** | Modification of `/etc/crontab` or `/var/spool/cron/crontabs` | Authorized Linux sysadmin maintenance | Inspect `auid`, `uid`, `exe`, and added cron command in `/etc/crontab`. |
| **Rule 10** | Linux SSH Authorized Keys Modification | `T1098.004` (Persistence) | `linux:audit` (`/var/log/audit/audit.log`, `key="ssh_keys"`) | **Medium** | Appending rogue public key to `~/.ssh/authorized_keys` | Legitimate DevOps key rotation | Compare added SSH public key fingerprint against authorized user inventory. |
